# 2. Документация

## 2.1. Подробное описание проекта

### Предметная область

Учёт сроков годности продуктов — задача, с которой сталкивается каждое домохозяйство. По данным исследований, около 30% приобретённых продуктов выбрасывается из-за истечения срока годности. Это приводит к финансовым потерям и негативному воздействию на экологию.

Традиционно контроль сроков годности осуществляется визуально: люди периодически проверяют холодильник и кладовую, ищут просроченные продукты. Однако такой подход неэффективен: продукты забываются в дальних углах, упаковки с датой оказываются скрыты, а регулярные проверки требуют времени и дисциплины.

Информационная система призвана автоматизировать этот процесс, предоставляя единую платформу для учёта продуктов, своевременных напоминаний и анализа потребительских привычек.

### Анализ существующих аналогов

| Сервис | Преимущества | Недостатки |
|--------|--------------|------------|
| NoWaste | Простой интерфейс, сканер штрихкодов | Нет русской локализации, слабая база российских продуктов |
| Fridgely | Хороший сканер, рецепты | Платные функции, нет семейного доступа |
| «Срок годности» (Android) | Бесплатно, русский язык | Устаревший интерфейс, нет аналитики, нет веб-версии |
| Listonic | Списки покупок | Нет учёта сроков годности |
| CozZo | Инвентаризация продуктов | Сложный интерфейс, переполнен функциями |

### Функциональные возможности системы

**Управление продуктами:**
- Добавление продукта вручную (название, категория, срок годности, количество)
- Сканирование штрихкода с автозаполнением данных (интеграция с Честный знак и Open Food Facts)
- Указание места хранения (холодильник, морозилка, кладовая, полка)
- Указание статуса: в наличии / заканчивается / использован / выброшен
- Редактирование и удаление продуктов
- Группировка по категориям и местам хранения

**Система уведомлений:**
- Push-уведомления за N дней до истечения срока (настраивается пользователем)
- Ежедневный дайджест «Истекает сегодня / завтра»
- Критические уведомления о просроченных продуктах
- Email-рассылка (опционально)
- Настройка расписания уведомлений

**Статистика и аналитика:**
- Количество использованных / выброшенных продуктов за период
- Расчёт экономии в рублях (на основе введённых цен)
- Категории с наибольшими потерями
- Тренды потребления по месяцам
- Средний процент утилизации
- Рекомендации по оптимизации закупок

**Список покупок:**
- Автоматическое добавление из закончившихся продуктов
- Ручное добавление позиций
- Отметка купленных товаров
- Перенос купленного в инвентарь с указанием срока годности

**Семейный доступ:**
- Создание домохозяйства
- Приглашение участников по email или ссылке
- Общий доступ к продуктам и статистике
- Роли: владелец / участник
- Синхронизация в реальном времени

**Личный кабинет:**
- Профиль пользователя
- Настройки уведомлений
- Управление домохозяйствами
- История действий
- Экспорт данных

### Роли пользователей

| Роль | Описание | Ключевые функции |
|------|----------|------------------|
| Гость | Неавторизованный посетитель | Просмотр описания сервиса, регистрация |
| Пользователь | Зарегистрированный участник | Все функции учёта продуктов, статистика, списки покупок |
| Владелец домохозяйства | Создатель семейного аккаунта | Все функции пользователя + управление участниками, настройки домохозяйства |
| Администратор | Технический специалист | Полный доступ, управление пользователями, модерация базы продуктов |

### Технологический стек

**Backend:**
- Язык: Python 3.11+
- Фреймворк: FastAPI
- ORM: SQLAlchemy 2.0
- База данных: PostgreSQL 15+
- Кэширование: Redis
- Очереди задач: Celery (отложенные уведомления)

**Frontend:**
- Фреймворк: React 18 или Vue 3
- Стилизация: Tailwind CSS
- PWA: для работы офлайн и push-уведомлений
- Сканер штрихкодов: QuaggaJS / ZXing

**Инфраструктура:**
- Контейнеризация: Docker, Docker Compose
- CI/CD: GitHub Actions
- Хостинг: VPS или облачная платформа

**Интеграции:**
- Честный знак API — получение данных о маркированных товарах (молочная продукция, вода, и др.), включая срок годности
- Open Food Facts API — fallback для международных продуктов
- SMTP-сервер — email-уведомления
- Firebase Cloud Messaging — push-уведомления

### Особенности интеграции с внешними API

**Честный знак (приоритетный источник для РФ):**
- Охватывает маркированные категории: молочная продукция, вода, пиво, табак
- Содержит точный срок годности из маркировки
- Требует регистрации в системе как участник оборота или потребитель

**Open Food Facts (дополнительный источник):**
- Открытая база данных продуктов
- Около 4 млн продуктов, но мало российских (≈753 с маркировкой EAC)
- Не содержит срок годности конкретной партии

**Гибридный подход:**
1. Сканирование штрихкода
2. Запрос к Честному знаку (если маркированный товар)
3. Fallback к Open Food Facts
4. Поиск в локальной базе ранее добавленных продуктов
5. Ручной ввод с сохранением в локальную базу для будущих сканирований

### Ограничения и допущения

1. Срок годности конкретной партии чаще всего вводится вручную (кроме маркированных товаров из Честного знака)
2. Система предназначена для домашнего использования, не для коммерческого учёта
3. Офлайн-режим ограничен ранее загруженными данными
4. Push-уведомления требуют разрешения пользователя в браузере
5. Точность статистики зависит от дисциплины пользователя при списании продуктов
