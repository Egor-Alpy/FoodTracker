# 1. Краткое описание проекта

## 1.3. Тема проекта
Проектирование и разработка информационной системы учёта сроков годности продуктов «FoodTracker»

## 1.4. Цель проекта
Разработка веб-приложения для домашнего учёта продуктов питания с контролем сроков годности, системой уведомлений и аналитикой потребления.

## 1.5. Задачи проекта
1. Провести анализ предметной области и существующих аналогов
2. Спроектировать архитектуру системы и базу данных
3. Разработать модели бизнес-процессов в нотациях IDEF0, DFD, BPMN
4. Создать UML-диаграммы структурного и поведенческого типов
5. Спроектировать ER-диаграмму и реализовать базу данных PostgreSQL
6. Разработать серверную и клиентскую части приложения
7. Реализовать интеграцию с внешними API (Честный знак, Open Food Facts)
8. Провести тестирование и документирование системы

## 1.6. Аннотация
Проект представляет собой веб-приложение для учёта продуктов питания в домашнем хозяйстве. Система позволяет добавлять продукты вручную или путём сканирования штрихкода, отслеживать сроки годности, получать уведомления об истекающих продуктах и вести статистику потребления. Реализованы функции семейного доступа к общему «холодильнику», автоматического формирования списка покупок и аналитики для сокращения пищевых отходов.
